ヘルプ

使用方法

  1. PythonPackageDownloader を起動する

  2. ダウンロード情報を入力する

    画面項目は以下のとおり。

    画面項目 説明
    ダウンロード方法 必須項目
    PyPISimpleとrequestsが未インストールの場合は強制的にpipを使う。
    pipを使う： ダウンロード環境の pip を使って pip download する
    pipを使わない： httpを使用パしてパッケージをダウンロードする
    OSを選択 Windows,Linux,macOS を選択する
    Pythonバージョン 必須項目,複数選択可
    ターゲットのpythonバージョンを選択する
    パッケージリスト 必須項目
    パッケージリスト(テキストファイル)のパスを指定する
    書式は pip install -r requirements.txt の requirements.txt と同じ
    ダウンロード先 必須項目
    ダウンロード先のフォルダを指定する。
    スクリプト格納場所の downloads が初期値
    pipのパス pipを使う場合必須項目
    ダウンロード環境にある pip を探して初期表示する
    プロキシを使用する
    ユーザ～ポート    		 任意項目
    プロキシを使う場合、入力する
    ソース形式を含める 任意項目
    ダウンロードできなかった場合、tar.gz形式のダウンロードを試みる
    依存関係をダウンロード ダウンロードしたパッケージの依存関係を調べて再帰的にダウンロードする
    パッケージに応じて所要時間が長くなるので注意

    「設定を保存」ボタンを押すと入力項目を保存する

  3. 「ダウンロード開始」ボタンを押す
