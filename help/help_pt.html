Ajuda

Uso

  1. Inicie o PythonPackageDownloader

  2. Insira as informações de download

    Os itens da tela são os seguintes:

    Item da tela Descrição
    Método de download Obrigatório
    Se PyPISimple e requests não estiverem instalados, o pip será usado forçadamente.
    Usar pip: Baixar pacotes usando pip download com o pip do ambiente de download
    Não usar pip: Baixar pacotes usando HTTP
    Selecionar SO Selecione Windows, Linux ou macOS
    Versão do Python Obrigatório, seleção múltipla permitida
    Selecione a versão do Python de destino
    Lista de pacotes Obrigatório
    Especifique o caminho para a lista de pacotes (arquivo de texto)
    O formato é o mesmo que requirements.txt usado em pip install -r requirements.txt
    Destino do download Obrigatório
    Especifique a pasta de destino do download.
    O padrão é a pasta downloads no local do script
    Caminho do pip Obrigatório ao usar pip
    Procura o pip no ambiente de download e o exibe inicialmente
    Usar proxy
    Usuário ~ Porta    		 Opcional
    Insira se estiver usando um proxy
    Incluir formato de origem Opcional
    Se o download falhar, tente baixar o formato tar.gz
    Baixar dependências Verifica as dependências dos pacotes baixados e baixa recursivamente
    Observe que o tempo de processamento pode aumentar dependendo do pacote

    Pressione o botão “Salvar configurações” para salvar os itens inseridos

  3. Pressione o botão “Iniciar download”
