Utilizzo

  1. Avviare PythonPackageDownloader

  2. Inserire le informazioni di download

    Gli elementi dello schermo sono i seguenti:

    Elemento dello schermo Descrizione
    Metodo di download Obbligatorio
    Se PyPISimple e requests non sono installati, pip verrà utilizzato forzatamente.
    Usa pip: Scarica i pacchetti usando pip download con il pip nell’ambiente di download
    Non usare pip: Scarica i pacchetti usando HTTP
    Seleziona sistema operativo Selezionare Windows, Linux o macOS
    Versione Python Obbligatorio, selezione multipla consentita
    Selezionare la versione Python di destinazione
    Elenco pacchetti Obbligatorio
    Specificare il percorso dell’elenco dei pacchetti (file di testo)
    Il formato è lo stesso di requirements.txt usato in pip install -r requirements.txt
    Destinazione download Obbligatorio
    Specificare la cartella di destinazione del download.
    Il valore predefinito è la cartella downloads nella posizione dello script
    Percorso pip Obbligatorio quando si usa pip
    Cerca pip nell’ambiente di download e lo visualizza inizialmente
    Usa proxy
    Utente ~ Porta    		 Opzionale
    Inserire se si utilizza un proxy
    Includi formato sorgente Opzionale
    Se il download fallisce, tentare di scaricare il formato tar.gz
    Scarica dipendenze Controlla le dipendenze dei pacchetti scaricati e scarica ricorsivamente
    Notare che il tempo di elaborazione può aumentare a seconda del pacchetto

    Premere il pulsante “Salva impostazioni” per salvare gli elementi inseriti

  3. Premere il pulsante “Avvia download”
