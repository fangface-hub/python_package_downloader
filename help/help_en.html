Usage

  1. Launch PythonPackageDownloader

  2. Enter download information

    Screen items are as follows:

    Screen Item Description
    Download Method Required
    If PyPISimple and requests are not installed, pip will be used forcibly.
    Use pip: Download packages using pip download with the pip in the download environment
    Don’t use pip: Download packages using HTTP
    Select OS Select Windows, Linux, or macOS
    Python Version Required, multiple selection allowed
    Select the target Python version
    Package List Required
    Specify the path to the package list (text file)
    The format is the same as requirements.txt used in pip install -r requirements.txt
    Download Destination Required
    Specify the download destination folder.
    Default is the downloads folder in the script location
    pip Path Required when using pip
    Searches for pip in the download environment and displays it initially
    Use Proxy
    User ~ Port    		 Optional
    Enter if using a proxy
    Include Source Format Optional
    If download fails, attempt to download tar.gz format
    Download Dependencies Check dependencies of downloaded packages and download recursively
    Note that processing time may increase depending on the package

    Press the “Save Settings” button to save the input items

  3. Press the “Start Download” button
