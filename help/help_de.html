Hilfe

Verwendung

  1. Starten Sie PythonPackageDownloader

  2. Geben Sie die Download-Informationen ein

    Die Bildschirmelemente sind wie folgt:

    Bildschirmelement Beschreibung
    Download-Methode Erforderlich
    Wenn PyPISimple und requests nicht installiert sind, wird pip zwangsweise verwendet.
    pip verwenden: Pakete mit pip download aus der pip-Umgebung herunterladen
    pip nicht verwenden: Pakete über HTTP herunterladen
    Betriebssystem auswählen Wählen Sie Windows, Linux oder macOS
    Python-Version Erforderlich, Mehrfachauswahl möglich
    Wählen Sie die Ziel-Python-Version
    Paketliste Erforderlich
    Geben Sie den Pfad zur Paketliste (Textdatei) an
    Das Format ist dasselbe wie requirements.txt in pip install -r requirements.txt
    Download-Ziel Erforderlich
    Geben Sie den Zielordner für den Download an.
    Standard ist der downloads-Ordner am Skriptstandort
    pip-Pfad Erforderlich bei Verwendung von pip
    Sucht nach pip in der Download-Umgebung und zeigt es initial an
    Proxy verwenden
    Benutzer ~ Port    		 Optional
    Eingeben, wenn ein Proxy verwendet wird
    Quellformat einbeziehen Optional
    Wenn der Download fehlschlägt, wird versucht, das tar.gz-Format herunterzuladen
    Abhängigkeiten herunterladen Prüft Abhängigkeiten der heruntergeladenen Pakete und lädt sie rekursiv herunter
    Beachten Sie, dass die Verarbeitungszeit je nach Paket zunehmen kann

    Drücken Sie die Schaltfläche “Einstellungen speichern”, um die Eingaben zu speichern

  3. Drücken Sie die Schaltfläche “Download starten”
