Ayuda

Uso

  1. Inicie PythonPackageDownloader

  2. Ingrese la información de descarga

    Los elementos de la pantalla son los siguientes:

    Elemento de pantalla Descripción
    Método de descarga Obligatorio
    Si PyPISimple y requests no están instalados, se usará pip forzosamente.
    Usar pip: Descargar paquetes usando pip download con el pip del entorno de descarga
    No usar pip: Descargar paquetes usando HTTP
    Seleccionar SO Seleccione Windows, Linux o macOS
    Versión de Python Obligatorio, selección múltiple permitida
    Seleccione la versión de Python de destino
    Lista de paquetes Obligatorio
    Especifique la ruta a la lista de paquetes (archivo de texto)
    El formato es el mismo que requirements.txt usado en pip install -r requirements.txt
    Destino de descarga Obligatorio
    Especifique la carpeta de destino de descarga.
    Por defecto es la carpeta downloads en la ubicación del script
    Ruta de pip Obligatorio cuando se usa pip
    Busca pip en el entorno de descarga y lo muestra inicialmente
    Usar proxy
    Usuario ~ Puerto    		 Opcional
    Ingrese si usa un proxy
    Incluir formato fuente Opcional
    Si la descarga falla, intente descargar el formato tar.gz
    Descargar dependencias Verifica las dependencias de los paquetes descargados y descarga recursivamente
    Tenga en cuenta que el tiempo de procesamiento puede aumentar según el paquete

    Presione el botón “Guardar configuración” para guardar los elementos ingresados

  3. Presione el botón “Iniciar descarga”
